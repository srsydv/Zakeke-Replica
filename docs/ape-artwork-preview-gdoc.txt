HOW WILL PDF, AI AND EPS FILES SHOW IN THE PREVIEW? WHAT HAPPENS IF ONE WON'T OPEN?

PNG, JPG, SVG, WebP, TIFF and HEIC are already pictures, so they go on the garment as they are. PDF, AI and EPS are print files, so the server makes a picture of them for the preview. The original file is stored either way, and the original is what the studio uses for production.


WHAT THE CUSTOMER SEES

The file is uploaded to private storage first, and checked there. The original is kept under the order, and staff can download it from admin.

The server then makes a flat preview image from the file:

A PDF is drawn from its first page.
An EPS is drawn with the same converter.
An AI file is drawn the same way when Illustrator has saved a PDF or EPS inside it, which is how most modern AI files are saved.

That preview image is what sits on the garment, at the position and size the customer chose. Removing a white background, and counting the colours for the price, is done on this preview only. It does not change the original file.


IF THE FILE WILL NOT OPEN

Some files cannot be drawn automatically. A password-protected PDF, a damaged file, or an older AI file with no PDF saved inside it are the usual cases.

The customer still sees the print position, at the size they chose, with a label on it: the file name, and the words “Preview unavailable. The studio will check this file.” They can carry on and place the order. The upload has not failed. Only the picture has.

The original file is already stored. In admin the studio downloads that original, opens it in their own software, and checks it during the artwork check. If it cannot be used, the customer gets the artwork-problem email and a secure link to upload a replacement, which is the flow already in the spec.

The placeholder is never sent to print. Production uses the original file, or the replacement the customer uploads.

If the preview could not be drawn, the builder cannot count the ink or thread colours from it. The customer is told the colour count will be confirmed on the proof. If the studio’s count changes the price, the customer pays the difference or receives a refund before production, by the same rule as any other price change after the proof.


WHAT THIS DOES NOT ADD

The converter runs on the server we already pay for. There is no extra paid service for opening these files.
